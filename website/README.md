# Kitari Studio website

This is the Next.js App Router and TypeScript application for the Kitari Studio
website. It uses Tailwind CSS, static export for Firebase Hosting, and a
reusable component foundation.

Start the development server with `npm run dev`. Check the code with
`npm run lint` and `npm run typecheck`; `npm run build` creates `out/` for
Firebase Hosting. See the root [README](../README.md) for project and Firebase
workflow notes.
